# Compass reference drift — the off-by-one-chair class

## What happened

Every stance-research run read
`C:/EV-Accounts/backend/data/stance-research/compass-topics-reference.md`, which was labelled
"Authoritative reference for stance research agents" but was a **hand-maintained paraphrase** of
`inform.compass_stances`. It had drifted.

**Fixed at the source 2026-08-14** — the file is now generated by
`C:/EV-Accounts/backend/scripts/gen-compass-topics-reference.mjs` and carries the chair text
verbatim, with a `--check` mode that fails when the committed copy is stale. Commit `a7d77751` on
EV-Accounts master. 44 topics / 220 chairs, up from 41 with 3 wrong exclusions.

**This todo is about the rows already written against the old text.**

## 🔑 Why no previous audit caught this

Migrations 1714 / 1727 / 1729 / 1730 all hunted **pole inversions** — a row sitting at the opposite
END of the ladder from its own reasoning. This class is different: the paraphrase was close enough to
look right while describing **the chair next door**. A pole-inversion scan cannot see a one-chair
error, so these topics were never examined at all.

## Rules for working it

- ⚠ **This is a READING QUEUE, not a delete list.** Every first cut over-fires. Match on what
  *distinguishes* the defect, not on what merely mentions the topic.
- A chair requires evidence describing **that chair**. If the drift means the row's own reasoning
  no longer identifies any specific chair, the answer is a **blank spoke**, not a nudged number.
- Check **which word** separates the candidate chairs before deciding it is fixable:
  pace/magnitude-only pairs cannot be settled by a sponsorship; end-state differences can.
- `city-sanitation` and `local-environment` are the hardest cases: the file asked a *different
  question*, so the stored reasoning may be **on-topic by vocabulary and off-topic by rationale** —
  it may not answer the live question at all. Those rows may need re-research, not re-seating.
- A wrong reason does not imply a wrong verdict. Rows can survive with corrected reasoning.
- Report the count of rows **read**, not the count matched by a regex.

## First step

Do **not** start with the 1,870-row topic. Start with `city-sanitation` (112) — smallest, and the
most likely to expose whether the drift produced re-seatable rows or rows needing full re-research.
That answer sets the method for the other five.
